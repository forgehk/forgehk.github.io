Distributed Smart ParkingFault tolerant distributed system, CECS 327Stdlib Python, Web Workers · 2026
cecs327-smart-parking.netlify.app

Coursework · Live demo · 2026

A distributed system you can crash from the browser.

Sensor nodes, lot servers and a driver client as separate processes talking over hand built TCP framing, idempotent request reply, a pub sub broker and registry based group messaging, all from the Python standard library. Group project of seven; 38 of the 40 commits are mine.
