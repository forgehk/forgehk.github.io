# forgehk.github.io

> My personal landing page, auto-deployed via GitHub Pages at **https://forgehk.github.io**.

[![Pages](https://img.shields.io/badge/GitHub_Pages-live-success.svg)](https://forgehk.github.io)
[![No build step](https://img.shields.io/badge/build-none-blue.svg)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A single `index.html` — no React, no Next, no build pipeline. Push to `main`, GitHub Pages serves it.

Sections:

- **Hero** — who I am, what I build
- **Projects** — every public repo, grouped by role bucket
- **Stack** — languages, full-stack, security, CS, DevOps
- **Open to** — roles I'm looking for + contact

If you want a copy for yourself, fork it and rename to `<your-username>.github.io`.
